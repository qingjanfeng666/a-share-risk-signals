# 股票风险观察页面

首次打开需用邮箱和密码注册或登录。登录会话由后端 Cookie 保存；各账户的查询历史互相隔离。

页面面向普通个人投资者：顶部输入六位 A 股代码并点击“查询股票”，系统就会抓取该股票最近已收盘日的数据并运行模型。成功结果自动保存，点“历史结果”可查看当前账户最近最多 100 条成功查询；同一天重复查询也分别保留。页面打开时先读取默认股票上次保存的结果；“刷新最新结果”会重新抓取和计算。结论卡显示是否触发短期下跌预警，并标明数据日期和抓取时间；三路模型分数与依据随后展示，新闻仅供阅读。

页面下方的趋势从该股票启用新功能后首次成功刷新的交易日开始，滚动显示最多 30 个交易日的行情模型和综合模型分数。手动刷新时会补算期间漏掉的交易日，并显示逐日进度；同一天重复刷新只替换趋势中的当天分数。补算失败的日期留空、下次刷新重试。2025 年独立测试集的回测数据只用于实验报告，不进入这张产品趋势图；趋势图也不提前生成未来日期的分数。

先按 [`backend/README.md`](../../backend/README.md) 在另一个 WSL 终端启动 FastAPI，再从项目根目录运行：

```bash
cd frontend/app
npm ci
npm run dev
```

在 WSL 中运行前端时，也要在 WSL 中执行 `npm ci`。Windows 与 Linux 的 `node_modules` 含有不同的原生模块，不能共用同一份安装结果；切换运行环境后需在目标环境重新安装依赖并重启开发服务。

在浏览器打开 `http://localhost:3000`。前端通过同源 `/api` 转发到后端；后端地址或端口变化时，在 `frontend/app/.env.local` 中设置 `BACKEND_INTERNAL_URL` 并重启前端。接口字段见 [`docs/api-contract.md`](../../docs/api-contract.md)。

若在 Windows 中修改 `/mnt/d/` 下的样式文件后，WSL 中运行的开发服务仍显示旧样式，停止 `npm run dev` 并重新启动，再在浏览器强制刷新。开发服务器的文件监视有时不能及时发现跨系统的文件改动。

```dotenv
BACKEND_INTERNAL_URL=http://127.0.0.1:8000
```

页面始终显示用于判断线比较的模型分数。完成新版模型训练、独立评估并刷新最新结果后，页面另显示经验证集校准的**模型估计**风险概率、20 日价格走势、5/10/20 日波动率、20 日最大回撤、成交量变化和公告情绪；它不是实际跌幅发生的保证。旧版保存结果仍显示旧分数，不能冒充新版结果。最新结果没有未来三日真实标签；新闻仅供展示，模型的文本输入来自公告。六位代码仍须有可获取的 A 股行情数据；模型仅对五只试点股票完成独立回测，其他股票结果会显示验证范围提示。
