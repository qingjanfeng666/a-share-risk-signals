# 风险信号舱界面方向

- **用户与任务**：普通个人投资者输入六位 A 股代码查询最近已收盘日的风险信号，再查看模型分数和使用过的依据。
- **首屏**：股票代码输入、综合风险结论、三路模型信号。综合结论最醒目；行情与公告模型并列解释。分数不表示真实下跌概率。
- **视觉**：明亮画布、深蓝文字、克制的预警色。只有结论主卡使用明显景深：三层信号板表达行情、公告汇入综合判断，不用概率仪表盘。其余内容以对齐和留白组织。
- **状态**：首次无结果、读取上次结果、正在刷新、刷新成功、刷新失败都保留清楚的文字。刷新失败不清除上次成功结果。每份结果显示基准日和抓取时间。
- **设备和动效**：笔记本与桌面优先，手机可完整阅读和操作。结论卡入场和分层图形有明显动效；系统设置减少动态效果时停用。
- **历史**：“历史结果”按钮展示所有股票每次成功查询的记录；页面底部滚动显示该股票启用新功能后最近 30 个交易日的行情与综合模型分数。2025 年独立测试集的回测仅用于实验报告。
